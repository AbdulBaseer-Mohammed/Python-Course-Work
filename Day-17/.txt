function in Python is a block of reusable code that performs a specific task.

Instead of writing the same code again and again, we can create a function and call it whenever we need it.


1. Why do we use functions?
1. To reuse code.
2. To reduce code repetition.
3. To make programs easier to understand.
4. To divide a big program into smaller parts.
5. To make debugging easier.
